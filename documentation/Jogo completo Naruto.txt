==================================================================

- projeto pessoal/familiar;

==================================================================
2. PREMISSA
==================================================================

O Arquivo Secreto de Jutsus Proibidos da Vila da Folha foi violado.

Uma organização misteriosa formada por:
- remanescentes da Akatsuki;
- ninjas renegados;
- cientistas proibidos;
- usuários de jutsus antigos;

fragmentou um pergaminho ancestral em dezenas de páginas espalhadas pelo mundo shinobi.

Se todas as partes forem reunidas:
- um jutsu proibido será ativado;
- o fluxo de chakra da Terra será corrompido;
- a história das vilas será reescrita.

A missão do jogador é:
- explorar o mundo ninja;
- recuperar pergaminhos;
- derrotar mini-bosses;
- descobrir segredos;
- impedir o colapso do mundo shinobi.

8. SISTEMAS PRINCIPAIS
==================================================================

8.1 CHAKRA SYSTEM

Substituir barra tradicional por:
🔵 Barra de Chakra

Regras:
- até 3 níveis;
- aura quando cheia;
- partículas únicas;
- efeitos por personagem.

Ganho de Chakra:
- atacar;
- realizar combos;
- derrotar inimigos;
- perfect dodge;
- defender;
- encontrar pergaminhos;
- ler textos;
- resolver segredos.

Concentração de Chakra:
- carregamento manual;
- pose ninja;
- vulnerabilidade;
- partículas leves.

--------------------------------------------------

8.2 TRIO SYSTEM

O jogador escolhe 3 ninjas antes da fase.

Regras:
- troca rápida;
- cooldown leve;
- animação ninja;
- estilos diferentes.

Sistema de Vida:
Quando um personagem morre:
- entra o próximo membro do trio.

Se todos morrerem:
- Game Over.

--------------------------------------------------

8.3 SUPPORT SYSTEM

Aliados podem:
- aparecer rapidamente;
- usar suporte;
- aplicar efeitos;
- possuir cooldown individual.

--------------------------------------------------

8.4 SPECIAL COMBO SYSTEM

Se:
- chakra máximo;
- membros vivos no trio;

permitir:
🔥 Ultimate combinado.

Exemplo:
Shikamaru prende →
Naruto finaliza com Rasengan gigante.

--------------------------------------------------

8.5 LAMEN SYSTEM

Lamen NÃO é vida extra.

Serve como:
- cura;
- buff;
- recompensa secreta.

Tipos:
- cura parcial;
- cura total;
- buff temporário.

Encontrado em:
- caixas;
- lojas;
- NPCs;
- segredos;
- áreas ocultas.

--------------------------------------------------

8.6 PERGAMINHOS

Os pergaminhos:
- contam lore;
- desbloqueiam progresso;
- revelam fraquezas;
- dão pistas.

Ao coletar:
- abrir tela anime estilizada;
- mostrar texto curto;
- recuperar chakra.

--------------------------------------------------

8.7 DIALOGUE SYSTEM

Adicionar:
- NPCs;
- diálogos;
- perguntas simples;
- pistas;
- lore;
- leitura rápida;
- humor leve.

Tudo deve ser:
- curto;

- divertido;
- natural.

--------------------------------------------------

8.8 SAVE SYSTEM

Implementar:

- save modular;
- progresso de personagens;
- progresso de pergaminhos;
- progresso de mapas.
